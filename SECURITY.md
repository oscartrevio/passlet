# Security Policy

## Supported Versions

The latest major version of `passlet` receives security fixes. After a new major is released, the previous major receives security fixes for 6 months.

## Reporting a Vulnerability

Do not open a public issue. Report privately through GitHub Security Advisories:
https://github.com/oscartrevio/passlet/security/advisories/new

Please include:

- Affected `passlet` version and runtime (Node/Bun/Deno + version)
- Provider involved (Apple, Google, or both)
- Description of the issue and its impact
- Minimal reproduction or proof of concept

## Response

Expect an acknowledgement within 7 days. Confirmed issues are fixed in a patch release and disclosed via the advisory once a fix is available.
